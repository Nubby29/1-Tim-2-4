Download Detailed Location Data

Download a reusable municipality Location Detail package: official Barangay boundaries, Purok / local areas, Subdivision / Village names, address components, and mapped landmarks / public-service places. Location names are sourced from Google Places/address text and official Philippine GeoRisk/PSA administrative data; Puroks are exhaustively indexed across the selected municipality and validated against Barangay boundaries. Road geometry, routing nodes, subdivision boundaries, and subdivision entry / exit nodes are managed separately by Download Road Data and are reused automatically when available.

Each municipality gets one reusable Location Detail package. This download does not request road geometry, routing nodes, subdivision boundaries, or subdivision entry / exit nodes. Official Barangay boundaries come from Philippine GeoRisk/PSA; local-area names and mapped places are searched through Photon/OpenStreetMap. Road datasets remain separate under Download Road Data and are linked locally when available. Address components and mapped landmarks are indexed locally for future searches.
Select a region, province, and municipality to download detailed location data.

Download Road Data

Download municipality-level OpenStreetMap road geometry separately. Road downloads use the standard OpenStreetMap map API in small areas, not Overpass. Existing road data is preserved, and later updates skip areas already downloaded.

Road requests are isolated from detailed-location requests and do not use Overpass. Select Region → Province → Municipality / City. Successful OpenStreetMap road areas are saved locally so later updates can skip areas already downloaded and continue with missing areas only.
Select a region, province, and municipality to download road data.

Cluster Folder Identity

Cluster folders are automatically named from the geographic center point of the people in each Cluster. The center is resolved against the detailed location data and Google address data.

Center-point Cluster names are generated automatically whenever groups are calculated.

Update Location Folders

Re-check saved coordinates and rebuild the final folder after Barangay using the strict hierarchy: Subdivision / Village only when inside its boundary and tied to a Purok; otherwise Purok; otherwise a nearby landmark.

Existing records are not changed until you run the update.
